## Dragon-Quest Mori Mori Recompilation 

A native Windows static recompilation project for **Dragon Quest: Slime Mori Mori (Shougeki no Shippo Dan)** from Gameboy Advance.

> **Note:** This project requires a legally dumped ROM of the original game to lift and generate the native executable binaries.

---

## Features

- **Widescreen Support**: Scalable aspect ratios up to 32:9.
- **High Framerate**: Unlocked 60 FPS gameplay.
- **Enhanced Audio**: Crisp playback and improved sound handling.
- **Flexible Controls**: Built-in support for both keyboard (Arrow keys) and controllers (Left thumbstick).
- **In-Game Settings Overlay**: Easy adjustments for resolution, audio, and visual enhancements.

---

## Getting Started

1. Download the latest release `.zip` from the Releases page[cite: 1].
2. Extract all files into a dedicated folder on your PC[cite: 1].
3. Run `SlimeMoriMoriRecomp.exe` to launch the game[cite: 1].

## Default Controls

### Keyboard
- **Movement:** Arrow Keys (`Up`, `Down`, `Left`, `Right`)
- **Action A / Accept:** `X`
- **Action B / Cancel:** `Z`
- **Shoulder Buttons:** `C` (L), `V` (R)
- **Triggers:** `Q` (L2), `E` (R2)
- **Start / Pause:** `Return` (Enter)
- **Select:** `Right Shift`

### Controller
- **Movement:** Left Thumbstick (or D-Pad)
- **Action Buttons:** Standard gamepad mappings (A, B, X, Y)
- **System:** Start & Select mapped to standard controller start/options buttons.

*(You can customize these keybinds anytime by editing the `keybinds.ini` file located next to the executable.)*
